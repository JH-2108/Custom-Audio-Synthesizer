# Custom-Audio-Synthesizer-
This custom audio synthesizer is a custom made, compact, standalone chiptune synthesizer built around an RP2040 development board. It allows users to create simple electronic melodies using eight playable keys, function buttons, and rotary encoders. 

The project combines embedded programming, basic audio electronics, PCB design, and enclosure design into a small musical instrument. 

# Features
- Eight playable keys for generating musical notes.
- Octave controls to change the pitch range.
- Sound mode selection for different synthesized tones.
- Two rotary encoders for adjusting sound parameters.
- Build-in speaker driven by an audio amplifier.
- RP2040-based control system
- Custom PCB and compact enclosure.

# Project goals 
The goal of this custom audio synthesizer project is to build and design an affordable, portable electronic instrument that demonstrates how a microcontroller can generate sound and respond to physical controls. 

The project focuses on keeping the design compact, minimizing component costs and making the hardware understandable and reproducible. 

# Planned controls 
| Control | Function | 
|---|---|
| Eight note keys | Play individual notes | 
| Octave-up button | Increase the playable pitch range | 
| Octave-down button | Decrease the playable pitch range | 
| Mode button | Change the sound mode | 
| Encoder 1 | Select sound settings or waveform | 
| Encoder 2 | Adjust an additional sound parameter | 

# Sound generation 
The RP2040 will generate digital audio using programmed waveforms. The audio signal will be sent to an amplifier, which drives the built-in speaker. 

Planned sound modes include square-wave tones, alternative synthesized waveforms, and simple arpeggiator effects, depending on the final firmware.
